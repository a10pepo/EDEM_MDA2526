## DBT

Crear un proyecto de dbt donde desarrolleis los modelos que considereis necesarios/utiles para responder posibles preguntas de negocio.
Podeis reutilizar los datos usados en clase (generando modelos adicionales o cambiando la estructura de los que ya hemos hecho en clase) o podeis usar vuestros propios datos. 

Cuando tengais vuestro proyecto listo, debereis presentar la documentación (con los detalles que sean necesarios para entenderlo, no es necesario descripciones en todas las columnas ni demasiado detalle).

Para subir la documentación bastará con subir el fichero `target/static_index.html`

Este fichero se genera/actualiza con el comando `dbt docs generate --static`.


Si alguien tiene algún problema para generar/subir la documentación, que suba directamente el proyecto de dbt para poder ver las macros/modelos.
