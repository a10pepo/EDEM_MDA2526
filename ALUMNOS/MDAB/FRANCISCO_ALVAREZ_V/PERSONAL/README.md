# 📚 Carpeta de Estudios MDA de Franciasco Alvarez Varas

Bienvenido/a a mi carpeta **`/personal/estudios`**, un espacio donde organizo mis materiales, apuntes y ejercicios relacionados con los distintos módulos de la universidad.  
He decidido mantener esta sección **dentro del repositorio personal** para centralizar mi aprendizaje, hacer seguimiento de mi progreso y, sobre todo, documentar el proceso de una forma más estructurada.

---

## 🎯 Propósito del directorio

El objetivo principal de esta carpeta es:

- **Consolidar** todos los recursos académicos que voy generando durante el curso.  
- **Practicar control de versiones** con Git y GitHub, aplicando buenas prácticas de documentación.  
- **Reflexionar sobre el aprendizaje**, incluyendo notas personales, ejemplos de código y proyectos prácticos.  
- **Demostrar crecimiento profesional**, combinando los conocimientos adquiridos en clase con aplicaciones reales en proyectos personales.
